分享與同步

這個網頁適合放在 GitHub Pages。沒有同步網址時，行程會照原本方式存在每台裝置自己的瀏覽器；設定 Google Apps Script Web App URL 後，手機和電腦就能手動拉取或推送同一份行程。

  1. 把這個資料夾推到 GitHub，並在 Settings → Pages 選 main branch / root。
  2. 開啟 Google Sheet 的 Apps Script，貼上本專案的 google-sheets-trip-app-script-2026-08-04.gs，部署為 Web app。
  3. Web app 權限選「任何知道連結的人」，把 /exec URL 貼到上方並儲存。
  4. 出門前在電腦按「更新到雲端」，手機開 GitHub Pages 網址後按「從雲端載入」。旅途中修改後，再按「更新到雲端」。
  5. 若網路不好，照常編輯；資料仍會先存在本機，晚點再同步。
